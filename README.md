# 📈 Stock Price Tracker

A desktop application that scrapes real-time stock data from the web, logs it into Excel files, and provides dynamic visualizations using PyQt5 and Plotly. This tool is perfect for monitoring stock trends, collecting historical prices, and viewing beautiful charts — all in one interface.

---

## 🚀 Features

- 🧠 **Real-time scraping** of multiple stock prices (Tesla, Apple, Google, etc.)
- 📊 **Interactive visualizations** using Plotly (Line, Bar, Area, and Candlestick charts)
- 📝 **Excel logging** with individual sheets for each stock
- 💡 **Company logos** displayed dynamically
- 🧵 **Multithreaded scraping** for smooth UI experience
- 🖥️ **Modern PyQt5 GUI** with responsive layouts
- 📤 **Exported HTML chart previews** rendered inside the app

---

## 📦 Tech Stack

- **Python 3.13+**
- **PyQt5** – GUI framework
- **Selenium / Web Scraping** (from `main.py`)
- **Pandas** – Data processing
- **Plotly** – Graph generation
- **OpenPyXL / Excel** – Data logging
- **Clearbit** – Company logos
- **QWebEngineView** – Embedded HTML rendering
